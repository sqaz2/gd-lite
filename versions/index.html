GET BACK TO MAKING

If loading or editing freezes

  1. If this page still responds: cancel the transfer and retry. Use “Back up original” before a bigger change.
  2. If the editor stops responding: open this recovery page in a new tab. Choose a saved project above, download its backup, or prepare a Lite copy.
  3. If the entire tab is frozen: use the browser’s address bar to open /versions/ on the same site. A frozen tab cannot run its own recovery button. Reload only after allowing any active save to finish.
  4. Keep browser storage: do not clear site data to fix a freeze. Recovery can read completed saves; edits and microphone samples that never reached storage cannot be recovered.

Lite and the full studio share a site. Lite2 lives on another site, so its local projects are separate. Moving between sites uses a downloaded transfer file: save it, open the destination’s transfer page, then choose that file.

A damaged backup, unsupported codec, exhausted storage or Lite’s 10-minute limit will show an error instead of silently dropping audio. Use Lite2 or Full for longer songs. Actual recording and playback depend on the phone and browser; these editions are not a guarantee for every older device.
